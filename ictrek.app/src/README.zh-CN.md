# PhotoCraft

PhotoCraft 是一个开源的、对标 Photoshop 的原生图像编辑器，用 Rust 写成一个引擎加多个前端。
本应用是它的**浏览器版本**：同一套 Rust 代码编译成 WebAssembly，在你的浏览器里跑，
不需要服务器端算力。

## 能做什么

- **图层体系**：图层、图层组、蒙版、矢量蒙版、剪贴蒙版、图层样式、混合模式、调整图层、智能对象。
- **绘画与修饰**：画笔引擎、形状动态、混合器画笔、仿制图章、修复画笔、污点修复、内容识别填充、液化。
- **选择与路径**：套索、魔棒、快速选择、色彩范围、钢笔与形状、路径运算、通道与快速蒙版。
- **色彩**：ICC 色彩管理，RGB / 灰度 / CMYK / Lab，8 位、16 位与 32 位浮点。
- **文字**：完整的文字工具、字符与段落面板、沿路径文字、OpenType 特性。
- **文件**：PSD / PSB 读写（与 Photoshop 往返一致）、`.pcraft` 原生格式、PNG / JPEG / TIFF / WebP /
  AVIF / HEIC / RAW 等常见格式的导入导出。
- **菜单与快捷键**：与 Photoshop 对齐的菜单结构、面板布局和快捷键体系。

## 在 VOS 里怎么用

- 在侧边栏打开 PhotoCraft 即可，它嵌在平台页面里；界面语言跟随浏览器，也可以在
  **编辑 › 首选项 › 界面** 里改。
- **文档只活在这个标签页里。** 这一版的打开/保存走浏览器自己的文件选择器与下载，
  不会写入 NAS，也没有服务器端会话。关掉标签页，未保存的内容就没了 —— 就像桌面版关窗口一样。
- 浏览器渲染优先使用 **WebGPU**，不支持时自动降到 **WebGL2**；如果画布异常，
  在地址后加 `?webgl`（强制 WebGL2）或 `?cpu`（强制 CPU 画布）再试。

## 容量与性能

- 大文档（比如几千像素、几十个图层）会占用较多内存，浏览器的内存上限通常低于桌面版，
  处理超大文件时建议先在桌面版里降采样或合并图层。
- 首次打开需要下载约 26 MB 的 wasm，之后会走浏览器缓存。
